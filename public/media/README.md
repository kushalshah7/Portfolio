# Hero media

The hero is already complete with a CSS-generated ambient fallback. For richer motion, add locally licensed and optimized files here:

- `hero-bg.webm` (preferred)
- `hero-bg.mp4` (fallback)
- `hero-poster.webp` (static / reduced-motion fallback)

Use a slow, dark abstract technology or data-network scene. Do not hotlink production video.
